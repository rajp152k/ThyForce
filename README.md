# ThyForce

>  For my ally is the Force, and a powerful ally it is. 

## Abstract

ThyForce is a long running personal software generation and maintenance infrastructure geared towards assimilating engineering acumen in an accelerated manner.  

I'm going for a healthy mix of being pragmatic and principled when exploring and integrating different engineering paradigms and patterns into this code base.  

The [seeding incentives](https://www.youtube.com/watch?v=2Gvud4Pceak) of the current repository structure ([polylith](https://polylith.gitbook.io/polylith) and tech stack choices (hy, python)) are (inexhaustive list):  
 - iteration speed (pragmatism of python + meta-linguistic (lispy) freedom of hy)  
 - build smaller composable utilities over monoliths (unix philosophy): the polylith idea enables easier composition and packaging of those granular utilities  
 - Super user native : prefer text io streams and api first approaches over UIs - this also accelerates agents; they display decent super user tendencies in the right ecosystems

Architectural meditations documented [here](https://thebitmage.com/categories/thyforce/)
